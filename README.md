# WE Medicine — Beyond the Single Target

A blog exploring the convergence of Western pharmacology and Eastern botanical medicine through a systems biology lens, inspired by the WE Medicine paradigm of Yung-Chi Cheng (Yale School of Medicine).

## Structure

```
we-medicine/
├── index.html          # Homepage
├── blog.html           # All posts / archive
├── about.html          # About the blog & paradigm
├── css/
│   └── style.css       # All styles
├── js/
│   └── main.js         # Filter, newsletter, animations
└── posts/
    └── manifesto.html  # Issue 001 — The foundational essay
```

## Deploying to GitHub Pages

1. Create a new GitHub repository (e.g. `we-medicine`)
2. Push this folder's contents to the `main` branch
3. Go to **Settings → Pages**
4. Set source to **Deploy from branch → main → / (root)**
5. Your site will be live at `https://yourusername.github.io/we-medicine/`

## Adding New Posts

1. Create a new `.html` file in `/posts/`
2. Copy the structure from `posts/manifesto.html`
3. Add a card for it in `blog.html`
4. Add a teaser in `index.html` if it's a featured piece
